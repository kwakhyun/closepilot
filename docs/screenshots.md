# 현재 제품 화면

추가 기능 검증 화면: [월별 정책 적용 이력](evidence/policy-applied-1280.png)은 1280px에서 현재 월 요율 적용과 재대사 요구를 보여 준다. [이월 근거 검토](evidence/followup-reviewed-320.png)는 320px에서 이전 마감과 이번 달 합성 정산을 연결한 검토 기록이다. 은행 입금 확인이나 거래 승인이 아니다.

2026-09-05 콘솔 리메이크 이후의 로컬 프로덕션 빌드를 Playwright로 확인한 화면이다. 모두 합성 데이터이며 실제 고객 자료나 운영 성과를 뜻하지 않는다. 화면마다 사용한 브랜드와 작업 단계가 다르므로 숫자를 하나의 마감 결과로 합쳐 해석하지 않는다.

제품 소개를 정리한 뒤 현재 화면의 안내와 가이드 캡처를 갱신했다. 합성 데이터 사용과 실제 결제 미처리 안내는 그대로 표시한다.

## 이미지 관리

2026-09-05 문구 교정 후 [1280px 보관함](evidence/workspace-library-1280.png)과 [320px 보관함](evidence/workspace-library-320.png)을 갱신했다. 두 화면은 2024년 2월 주문 3행을 반영한 작업과 2024년 1월의 완료된 합성 마감을 함께 보관한 상태다. 모바일 캡처는 보관함 상단이며 나머지 작업은 아래로 스크롤해 확인한다.

캡처는 `e2e/workspace.spec.ts`의 기존 사용자 흐름에서 생성한다. 애니메이션이 끝난 상태와 이미지 로딩을 확인하며, 파일은 `test-results/`에 생성된 뒤 직접 확인한 것만 문서에 반영한다. README와 가이드용 이미지의 원본은 `public/console-preview.png` 하나로 유지한다. 가이드는 정적 이미지 import를 사용해 원본이 바뀌면 빌드된 이미지 URL도 바뀌도록 한다.

`verification.md`와 `verification-history.md`의 과거 화면은 해당 날짜의 실행 근거다. 최신 이미지로 덮어쓰지 않는다. 현재 소개와 맞지 않는 문구가 포함된 과거 캡처 3장은 공개 목록에서 제외하고 원본을 로컬에 별도 보존했다. 당시 검증 결과는 문서에 유지하며 현재 화면은 위 목록에서 확인한다. 공개 배포의 완료 여부는 스크린샷만으로 판단하지 않고 별도 배포 상태와 응답을 확인한다.
