# 고객 발견 기록 템플릿

이 문서는 실제 고객 인터뷰를 진행한 뒤 검증된 사실과 제품 가설을 구분해 남기기 위한 템플릿이다. 현재 저장소에는 실제 인터뷰 결과가 없으며, 아래 항목도 작성 예시가 아닌 빈 기록 구조다.

## 인터뷰 정보

- 일시:
- 참여자 역할과 업종:
- 인터뷰어:
- 기록 및 활용 동의 범위:
- 개인·회사 식별 정보 제거 여부:

## 현재 업무 흐름

1. 월 마감에 사용하는 입력 자료:
2. 자료를 받는 시점과 담당자:
3. 대사 기준과 예외 유형:
4. 검토와 승인 주체:
5. 마감 결과를 넘기는 대상과 형식:

## 관찰과 직접 확인한 사실

해석을 섞지 않고 참여자가 설명하거나 화면에서 확인한 사실만 기록한다. 인용이 필요하면 동의 범위 안에서 짧게 남기고, 민감 정보는 제거한다.
