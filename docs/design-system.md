# ClosePilot 콘솔 디자인

## 화면 기준

흰색 작업 공간, 중립 회색 구분선과 파란색 주요 동작을 사용한다. 외부 서비스명이나 로고는 제품 화면에 넣지 않는다. 브랜드는 ClosePilot이며 합성 데이터 데모라는 표시를 유지한다.

- 주요 동작: `--accent` #3563e9, 선택 상태: #edf2ff
- 본문: `--ink` #20242c, 보조 문구: `--muted` #626b79
- 구분선: `--line` #e5e7eb, 보조 표면: #f6f7f9
- 정상 상태: 녹색, 확인 필요: 황색, 큰 차이와 오류: 적색. 색상과 함께 텍스트를 표시한다.
- 글꼴은 로컬 Pretendard를 유지하고 자간은 0으로 통일한다. 숫자는 고정 폭 숫자 옵션을 사용한다.
- 주요 구역은 구분선으로 나누고 반복 항목과 대화상자만 테두리로 묶는다. 둥근 모서리는 최대 8px이다.

`src/app/globals.css`는 공통 레이아웃과 상태별 규칙, `src/app/console.css`는 콘솔의 공통 시각 기준을 담당한다. 증빙, 추가 도구와 가이드는 해당 CSS 파일을 사용한다. 기존 녹색 계열의 하드코딩 값과 토큰 이름은 중립 색상 및 의미 중심 이름으로 정리했다.

## 작업 이동

대시보드의 단계 표시에서 자료 관리, 전체 대사 결과, 미검토 거래와 마감 점검으로 이동한다. 단계 클릭 자체는 서버 명령을 실행하지 않는다. 실제 재대사, 승인과 마감은 기존 조건을 검사하는 명령으로 수행한다.

설정 화면은 브랜드 설정, 월별 작업과 정책 비교로 나눈다. 기간 선택 버튼은 월별 작업 화면으로 이동한다. 설정 보기는 일반 버튼 그룹이며 Tab으로 이동하고 Enter 또는 Space로 선택한다. 선택 여부는 `aria-pressed`로 제공한다.

작은 화면에서는 메뉴를 접고 거래 목록을 지표보다 먼저 제공한다. 주요 금액은 기본 샘플에서 줄바꿈되지 않게 조정하며, 긴 입력과 최대 한도 금액의 경우 내용이 겹치지 않도록 줄바꿈을 허용한다. 키보드 포커스, Escape 닫기, 동작 중 중복 제출 차단과 확인란을 유지한다.

제품 가이드의 이미지는 이 프로젝트의 실제 합성 화면을 캡처한 것이다. 외부 서비스의 화면이나 브랜드 자산을 제품에 복사하지 않는다.

## 변경하지 않는 경계

표시 변경으로 원본 금액, 대표 대사 분류, 승인 fingerprint, 저장 메모와 마감 증빙을 바꾸지 않는다. API, SQL과 계산 규칙의 변경 없이 화면 계층만 수정한다. 새 디자인에서도 전체 CSV 반영, 재대사, 검토와 마감 시나리오를 검증한다.
